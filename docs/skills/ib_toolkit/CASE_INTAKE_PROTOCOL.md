# Case Study Intake Protocol
## Middle Market Transaction Analysis Framework

*Version: 1.0.0 | Created: 2026-02-04*
*Focus: Interview case studies (2-4 hour take-home, 45-60 min live)*

---

## Quick Start: First 10 Minutes

When you receive a case study email with materials, execute this intake sequence:

```
┌─────────────────────────────────────────────────────────────────────┐
│ STEP 1: IDENTIFY CASE TYPE (2 min)                                  │
│ What are they actually asking you to do?                            │
├─────────────────────────────────────────────────────────────────────┤
│ STEP 2: INVENTORY MATERIALS (3 min)                                 │
│ What did they give you? What's missing?                             │
├─────────────────────────────────────────────────────────────────────┤
│ STEP 3: IDENTIFY DELIVERABLES (2 min)                               │
│ What outputs are expected? In what format?                          │
├─────────────────────────────────────────────────────────────────────┤
│ STEP 4: SELECT MODULES (3 min)                                      │
│ Which analysis blocks do you need to complete?                      │
└─────────────────────────────────────────────────────────────────────┘
```

## Step 1: Case Type Identification

### Middle Market Case Archetypes

| Case Type | You're Given | You Produce | Time Allocation |
|-----------|--------------|-------------|-----------------|
| **A. Model Build** | CIM + blank/partial Excel | Completed LBO/DCF model | 70% model, 30% memo |
| **B. Model Analysis** | CIM + completed model | Investment recommendation | 30% model review, 70% analysis |
| **C. Investment Memo** | CIM + model + data | Written memo or slides | 20% model, 80% writing |
| **D. Deal Structuring** | Term sheet + financials | Sources/uses, returns scenarios | 50% structure, 50% analysis |
| **E. Due Diligence** | CIM + management notes | DD question list + red flags | 100% qualitative analysis |
| **F. Valuation** | Financials + comps | Valuation range + support | 60% quantitative, 40% narrative |

### Quick Identification Questions

Ask yourself:
1. **Is there a model to build or just analyze?**
   - Blank Excel → Type A (Model Build)
   - Completed model → Type B or C

2. **What's the primary deliverable?**
   - Excel model → Type A, D, or F
   - Written memo → Type C
   - Question list → Type E
   - Recommendation → Type B

3. **What's the time constraint?**
   - <2 hours → Focus on ONE module deeply
   - 2-4 hours → 2-3 modules possible
   - Take-home (24-48 hrs) → Full analysis

## Step 2: Material Inventory

### Standard Middle Market Case Materials

| Material | What to Extract | Red Flag if Missing |
|----------|-----------------|---------------------|
| **CIM / Teaser** | Revenue, EBITDA, growth rates, business description | Can't do the case |
| **Historical Financials** | 3-5 years P&L, balance sheet | Limited model accuracy |
| **Management Projections** | 5-year forecast, assumptions | Must build your own |
| **Excel Model (if provided)** | Structure, formulas, assumptions tab | N/A if build case |
| **Industry Data** | Comps, market size, trends | Use judgment/proxies |
| **Deal Terms** | Purchase price, structure, timing | Assume or ask |

### 3-Minute Material Scan Checklist

```
□ CIM/Teaser present? _____ pages
□ Historical financials? _____ years
□ Projections provided? □ Yes □ No → Must build
□ Excel model? □ Complete □ Partial □ Blank □ None
□ Purchase price given? □ Yes □ No → Assume ___x EBITDA
□ Debt terms provided? □ Yes □ No → Use market terms
□ Comps/precedents? □ Yes □ No → Research or estimate
□ Specific questions to answer? List: _____________________
```

## Middle Market Specifics

### What Makes Middle Market Different

| Factor | Middle Market ($25M-$500M EV) | Large Cap ($1B+) |
|--------|------------------------------|------------------|
| **Leverage** | 3-4x senior, 4-5x total | 5-6x+ achievable |
| **Equity Check** | 40-50% of TEV | 30-40% of TEV |
| **Management** | Often thin, key-person risk | Deep bench |
| **Information** | Limited, unaudited common | Robust, audited |
| **Exit** | Strategic sale most likely | IPO possible |
| **Hold Period** | 4-6 years typical | 3-5 years |
| **Value Creation** | Operational, buy-and-build | Financial engineering |
| **Due Diligence** | More operational focus | More financial focus |

### Middle Market Red Flags to Always Check

1. **Customer Concentration** - Top 10 customers >50% revenue?
2. **Key Person Risk** - Founder/CEO departure impact?
3. **Working Capital** - Cash conversion cycle, seasonality?
4. **Capex Requirements** - Deferred maintenance, growth capex?
5. **Quality of Earnings** - Add-backs, normalizations, one-timers?
6. **Debt Capacity** - Asset-light? Sufficient collateral?
7. **Management Depth** - Who runs the business post-close?
8. **Customer Contracts** - Change of control provisions?

### Middle Market Financing Assumptions (2026 Market)

Use these defaults if not provided:

| Debt Type | Multiple | Rate | Amortization |
|-----------|----------|------|--------------|
| Revolver | 0.5-1.0x | SOFR + 350-450 | — |
| Term Loan A | 1.5-2.5x | SOFR + 400-500 | 5-7 yr, 5-10% annual |
| Term Loan B | 1.0-1.5x | SOFR + 500-600 | 7 yr, 1% annual |
| Unitranche | 4.0-5.0x | 10-12% (fixed or SOFR + 650) | 6-7 yr, 1% |
| Mezzanine | 0.5-1.5x | 12-14% cash + 2% PIK | Bullet |
| **Total Leverage** | **4.0-5.5x** | — | — |

## Case Type Quick-Start Guides

### Type A: LBO Model Build

**First 15 minutes:**
1. Extract from CIM: LTM Revenue, EBITDA, growth assumptions
2. Identify purchase price (given or calculate from multiple)
3. Note debt terms if provided
4. Set up Excel structure: Assumptions | S&U | OpModel | Debt | Returns

**Model Build Order:**
```
1. Assumptions tab (15 min)
   - Entry multiple, purchase price
   - Revenue growth, margin assumptions
   - Debt terms, interest rates

2. Sources & Uses (10 min)
   - Purchase price + fees + cash to BS
   - Debt tranches + equity

3. Operating Model (30 min)
   - Revenue build
   - EBITDA bridge
   - D&A, Capex, NWC
   - Free cash flow

4. Debt Schedule (20 min)
   - Opening balances
   - Mandatory amort
   - Cash sweep
   - Interest expense

5. Returns (15 min)
   - Exit enterprise value
   - Exit equity value
   - MOIC, IRR
   - Sensitivity tables
```

### Type B: Model Analysis (Given Completed Model)

**First 15 minutes:**
1. Open model, go to Assumptions tab - understand key drivers
2. Go to Returns tab - note base case MOIC/IRR
3. Identify which inputs are most sensitive
4. Read CIM executive summary

**Analysis Framework:**
```
1. Validate the model (15 min)
   - Check S&U balances
   - Check debt schedule ties to cash flow
   - Check returns math
   - Identify any errors

2. Stress test assumptions (20 min)
   - Revenue: What if 20% miss?
   - Margins: What if 200bps lower?
   - Exit multiple: What if 1x lower?
   - Create scenario table

3. Identify value creation levers (15 min)
   - Revenue growth sensitivity
   - Margin expansion sensitivity
   - Debt paydown contribution
   - Multiple expansion contribution

4. Form recommendation (20 min)
   - Is base case achievable?
   - What's the downside?
   - What must go right?
   - Buy / Pass / More DD needed
```

### Type C: Investment Memo

**Structure (2-3 pages):**
```
I. Executive Summary (1/2 page)
   - Company, deal, recommendation
   - Key metrics, returns

II. Business Overview (1/2 page)
   - What they do
   - Market position
   - Key customers

III. Investment Thesis (1/2 page)
   - 3 reasons to invest
   - Supporting evidence

IV. Key Risks (1/2 page)
   - Top 3 risks
   - Mitigants

V. Financial Summary (1/2 page)
   - Historical performance
   - Projected returns
   - Sensitivity

VI. Recommendation (1/4 page)
   - Final verdict
   - Conditions/gates
```

### Type E: Due Diligence Questions

**Organize by Category:**
```
1. FINANCIAL (5-8 questions)
   - Revenue quality, recognition
   - EBITDA add-backs validation
   - Working capital patterns
   - Capex requirements

2. COMMERCIAL (5-8 questions)
   - Customer concentration
   - Contract terms, renewals
   - Win/loss dynamics
   - Pricing power

3. OPERATIONAL (5-8 questions)
   - Key processes
   - Technology/systems
   - Capacity utilization
   - Supply chain

4. MANAGEMENT (3-5 questions)
   - Depth of team
   - Retention plans
   - Incentive alignment

5. LEGAL/OTHER (3-5 questions)
   - Litigation
   - Regulatory
   - Environmental
   - Change of control
```

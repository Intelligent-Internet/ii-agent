# IR Slide Layout Templates — Infrastructure

*Visual design guide for LP-facing presentations. ASCII diagrams showing exact layouts for each slide type.*

---

## Design Standards

### Color Palette

| Element | Hex | Use |
|---------|-----|-----|
| Primary (Headers) | `#1F4E79` | Slide titles, section headers, stat boxes |
| Secondary | `#2C5282` | Sub-headers, chart accents |
| Body Text | `#333333` | All body copy |
| Positive | `#28A745` | Top-quartile metrics, above-benchmark |
| Negative | `#DC3545` | Below-benchmark, loss positions |
| Neutral Accent | `#6C757D` | Secondary text, footnotes |
| Light Background | `#F8F9FA` | Alternating table rows, callout boxes |
| White | `#FFFFFF` | Slide background |

**Why Navy + White:** This is the institutional standard for PE/infra fundraising materials. It signals stability and professionalism. LPs see hundreds of pitchbooks per year — they trust the ones that look like every other credible firm's.

### Typography

| Element | Font | Size | Weight |
|---------|------|------|--------|
| Slide Title | Arial or Calibri | 22-26pt | Bold |
| Sub-Header | Arial or Calibri | 16-18pt | Bold |
| Body Text | Arial or Calibri | 11-13pt | Regular |
| Table Header | Arial or Calibri | 10-11pt | Bold |
| Table Body | Arial or Calibri | 9-10pt | Regular |
| Footnote / Source | Arial or Calibri | 7-8pt | Regular, Gray |
| Large Stat (banner) | Arial or Calibri | 36-44pt | Bold |

### Required Elements

Every slide must include:
- **"CONFIDENTIAL"** in bottom-left footer
- **Slide number** in bottom-right
- **Fund logo** top-left (placeholder if not provided)
- **Date / "As of" reference** for any performance data

**Purpose:** Establish GP credibility. LPs invest in people and platforms first.

```
+-------------------------------------------------------------+
|  Firm Overview                                              |

|  | FOUNDED  |  |   AUM    |  |  FUNDS   |  |   TEAM   |    |
|  |   2008   |  |  $8.5B   |  |    IV    |  |   45+    |    |
|  +----------+  +----------+  +----------+  +----------+    |
|                                                             |
|  [GP Name] is a global infrastructure investment firm       |
|  focused on essential services assets in OECD markets.      |
|  Founded in [year] by [founders], the firm has invested     |
|  across [X] assets generating [Y]% cash yield.              |
|                                                             |
|  KEY MILESTONES:                                            |
|  * 2008: Founded; Fund I ($500M)                            |
|  * 2012: Fund II ($1.2B); first exits                       |
|  * 2017: Fund III ($2.5B); European expansion               |
```

**Design Notes:**
- Stat banner at top with 4 key numbers in navy boxes, white text
- Brief narrative paragraph (3-5 sentences max)
- Timeline/milestones to show progression
- Keep factual — no superlatives ("world-class," "best-in-class")

```
|                                                             |
|  +-------+--------+-------+-------+------+------+------+   |
|  | Fund  |Vintage | Size  |Net IRR|Net   | DPI  | TVPI |   |
|  |       |        |       |       |MOIC  |      |      |   |

|  | II    | 2012   | $1.2B | 12.8% | 1.7x | 1.4x | 1.7x |   |
|  | III   | 2017   | $2.5B | 11.5% | 1.5x | 0.6x | 1.5x |   |
|  +-------+--------+-------+-------+------+------+------+   |
|  | Agg.  |        | $4.2B | 12.6% | 1.7x | 1.2x | 1.7x |   |
|  +-------+--------+-------+-------+------+------+------+   |
|                                                             |
|  BENCHMARK CONTEXT:                                         |
|  Infra median Net IRR: 9.5% | Top quartile: 12.0%          |

|                                                             |
```

**Design Notes:**
- Clean performance table with clear column headers
- **DPI is critical** — LPs increasingly care about cash-on-cash returns
- Benchmark comparison essential — show quartile ranking
- Green highlight for metrics above top-quartile threshold
- Footnotes: "As of [date]. Past performance is not indicative of future results."
- **Infra-specific:** Include cash yield / distribution history

## Slide 7: Asset Case Study

**Purpose:** Deep-dive into one asset to illustrate value creation in action.

```
+-------------------------------------------------------------+
|  Case Study: WindCo — Onshore Wind Portfolio                |
+-------------------------------------------------------------+
|                                                             |
|  OVERVIEW:                                                  |
|  400 MW onshore wind portfolio across 3 sites in Texas.     |
|  Acquired in 2018 for $180M (10x EBITDA). 15-year PPAs      |
|  with investment-grade utilities.                           |
|                                                             |
|  +--- AT ENTRY ---+              +--- TODAY ---+            |
|  | Capacity: 350MW|    ---->     | Capacity: 400MW|          |
|  | Availability:  |              | Availability:  |          |
|  |   92%          |              |   97%          |          |
|  | EBITDA: $18M   |              | EBITDA: $28M   |          |
|  | Contract Life: |              | Contract Life: |          |
|  |   15 years     |              |   12 years     |          |
|  +----------------+              +----------------+          |
|                                                             |
|  VALUE CREATION LEVERS:                                     |
|  1. Capacity Expansion: Added 50MW brownfield (+$4M EBITDA) |
|  2. Availability Improvement: O&M optimization (+500bps)    |
|  3. Contract Extension: Negotiated 5-year extension         |
|                                                             |
|  CURRENT STATUS: Unrealized | MOIC: 1.7x | Cash Yield: 7%   |
|                                                             |
+-------------------------------------------------------------+
```

**Design Notes:**
- Choose fund's best example (highest MOIC or most illustrative)
- Before/After framework makes value creation tangible
- Numbered value creation levers show repeatable playbook
- **Infra-specific:** Include availability, contract life, cash yield

## Slide 10: Risk Management

**Purpose:** Show systematic approach to managing infra-specific risks.

```
+-------------------------------------------------------------+
|  Risk Management Framework                                  |
+-------------------------------------------------------------+
|                                                             |
|  +----------------------------------------------------------+
|  | Risk Category    | Key Risks        | Mitigants          |
|  +----------------------------------------------------------+
|  | Regulatory       | Tariff resets,   | Focus on stable    |
|  |                  | policy changes   | regulatory regimes |
|  +----------------------------------------------------------+
|  | Counterparty     | Off-taker credit | IG-rated counter-  |
|  |                  | deterioration    | parties, diversify |
|  +----------------------------------------------------------+
|  | Operational      | Availability     | Best-in-class O&M, |
|  |                  | shortfalls       | performance bonds  |
|  +----------------------------------------------------------+
|  | Market           | Merchant price   | Max 25% merchant   |
|  |                  | volatility       | exposure           |
|  +----------------------------------------------------------+
|  | FX / Rates       | Currency and     | Natural hedges,    |
|  |                  | interest rate    | match funding      |
|  +----------------------------------------------------------+
|                                                             |
|  PORTFOLIO LIMITS:                                          |
|  * Single asset: <15% of fund   * Merchant: <25% of revenue |
|  * Single sector: <40%          * Single country: <50%      |
|                                                             |
+-------------------------------------------------------------+
```

**Design Notes:**
- Risk table with clear categories, specific risks, and mitigants
- Portfolio limits/concentration guidelines
- **Infra-specific:** Focus on regulatory, counterparty, operational risks

# Infrastructure IR Jargon & Metrics

Reference guide for infrastructure-specific terminology and KPIs.

## Cash Flow Metrics

| Metric | Definition | Typical Use |
|--------|------------|-------------|
| **FFO** | Funds From Operations | Cash flow proxy for infra/REIT reporting |
| **AFFO** | Adjusted FFO | FFO less maintenance capex and recurring items |
| **Cash Yield** | Distributions / Invested Capital | Return measure emphasizing cash generation |
| **DPI** | Distributions to Paid-In | Realized return multiple |
| **RVPI** | Residual Value to Paid-In | Unrealized return multiple |
| **TVPI** | Total Value to Paid-In | DPI + RVPI |

## Return Metrics

| Metric | Definition | Notes |
|--------|------------|-------|
| **Net IRR** | Internal Rate of Return (net of fees) | Primary return measure |
| **Gross IRR** | IRR before fees/carry | Used for attribution |
| **GP IRR** | Return to general partner | Includes carry |
| **LP IRR** | Return to limited partners | Net of all fees |
| **MOIC** | Multiple on Invested Capital | Entry vs. exit value |
| **PME** | Public Market Equivalent | Benchmark comparison |

## Contracted & Regulated Metrics

| Metric | Definition | Target Range |
|--------|------------|--------------|
| **Contracted Revenue %** | Revenue under long-term contracts | 70-95% |
| **WACL** | Weighted Average Contract Life | 8-15 years |
| **Regulated vs. Merchant** | Revenue split by type | Varies by strategy |
| **Rate Base** | Asset value earning regulated return | Growing = positive |
| **Allowed ROE** | Regulated return on equity | 9-12% typically |

## Operational KPIs

| Metric | Definition | Target |
|--------|------------|--------|
| **Availability** | Uptime / total time | >95% |
| **Utilization** | Actual / capacity | Varies |
| **Capacity Factor** | Output / max output | 30-90% by asset |
| **TRIR** | Total Recordable Incident Rate | <1.0 |
| **LTIR** | Lost Time Incident Rate | <0.5 |

## Capital Structure Metrics

| Metric | Definition | Healthy Range |
|--------|------------|---------------|
| **DSCR** | Debt Service Coverage Ratio | >1.3x |
| **ICR** | Interest Coverage Ratio | >3.0x |
| **Debt/EBITDA** | Leverage ratio | <5.0x |
| **LTV** | Loan to Value | <60% |
| **Covenant Headroom** | Buffer to covenant breach | >15% |

## Inflation & Macro Metrics

| Metric | Definition | Notes |
|--------|------------|-------|
| **CPI Linkage %** | Revenue indexed to inflation | Higher = more protected |
| **Pass-Through Lag** | Delay in inflation recovery | Months |
| **Real Return** | Nominal return - inflation | Focus for infra |
| **FX Exposure** | Non-base currency % | Hedge target |

## Fund Metrics

| Metric | Definition | Notes |
|--------|------------|-------|
| **Vintage** | Year of first capital call | Fund age reference |
| **Commitment Period** | Investment period length | Typically 3-5 years |
| **Fund Life** | Total duration | 10-15 years for infra |
| **Called Capital** | Cumulative capital calls | % of commitment |
| **Unfunded** | Remaining commitment | Dry powder |

## LP Communication Phrases

### Positive Framing
- "Stable, contracted cash flows"
- "Inflation-protected revenue"
- "Regulated rate-base growth"
- "Conservative leverage and strong coverage"
- "Essential service infrastructure"
- "Long-duration, predictable returns"

### Risk Acknowledgment
- "Regulatory reset exposure is manageable"
- "Merchant exposure is limited to X%"
- "Capex is within budget"
- "Coverage remains robust under stress"

### Performance Attribution
- "Returns driven by cash yield and modest multiple expansion"
- "NAV growth reflects operational improvements"
- "Distributions supported by contracted revenue"

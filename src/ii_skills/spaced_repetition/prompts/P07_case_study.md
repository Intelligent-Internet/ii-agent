## Instructions

Create flashcards specific to a deal or case study:

**Extract and test:**
- Company overview (sector, size, geography, business model)
- Key financial metrics (revenue, EBITDA, margins, growth rates)
- Deal structure (purchase price, multiple, sources & uses)
- Investment thesis bullets (growth drivers, margin expansion, add-ons)
- Key risks and mitigants
- Management team highlights
- Competitive landscape / market positioning
- Value creation plan (operational, financial, strategic)

**Question format:**
- Use `**Org:**` prefix for company-specific facts
- Direct — "**Org:** [Company] LTM EBITDA?"
- Include count for lists
- Test both facts and thesis logic

**Answer format:**
- Single line, keywords + numbers
- `(1) Item, (2) Item` numbered format for lists
- Include dollar figures, percentages, multiples where available

**Rules:**
- One fact per card
- Separate financial metrics from thesis points
- Include "So what?" cards that test why a metric matters

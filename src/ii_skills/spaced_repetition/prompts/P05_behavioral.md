## Instructions

Create flashcards for behavioral/fit interview preparation:

**Question types:**
- "Tell me about a time when..." → STAR framework prompts
- "Why [firm/role/industry]?" → Key talking points
- "Walk me through your resume" → Transition narratives
- "Greatest strength/weakness?" → Structured self-assessment
- Leadership, teamwork, conflict resolution scenarios
- "Why should we hire you?" → Value proposition bullets

**Question format:**
- Direct prompt — no filler
- Include the behavioral cue (e.g., "STAR: Describe a time you led under pressure?")

**Answer format:**
- Framework + key bullets, not a full story
- `(1) Situation, (2) Task, (3) Action, (4) Result` for STAR cards
- For "Why X?" cards: 3 concise reasons
- Keywords only — prompts for recall, not scripts

**Rules:**
- One scenario per card
- Separate the setup (question) from the framework (answer)
- Include cards for common follow-ups ("What would you do differently?")

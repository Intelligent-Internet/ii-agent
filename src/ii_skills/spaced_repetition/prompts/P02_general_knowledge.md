## Instructions

Create flashcards from the provided notes. Each card should:

**Questions:**
- Be direct and specific — no filler words
- Include count when asking for lists
- Test a single fact or concept

**Answers:**
- Single line, keywords only
- Use `(1) Item, (2) Item` numbered format for lists
- No full sentences

**Rules:**
- Break complex ideas into multiple simple cards
- One testable fact per card
- Cover all key points from the source notes
- If a concept has sub-components, make separate cards for each

## Output Format

```
Question text here?
Answer text here

Next question?
Next answer
```

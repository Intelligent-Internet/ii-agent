# Agent Learnings

This folder contains self-improvement logs from agent sessions. Each file captures lessons learned, mistakes corrected, and improvements identified.

## Purpose

When the agent makes a mistake, discovers a better approach, or learns something new, it should log the insight here. These learnings persist across sessions and can inform future behavior improvements.

## File Naming Convention

```
YYYY-MM-DD-<topic>.md
```

Examples:
- `2026-02-04-api-rate-limiting.md`
- `2026-02-04-excel-generation-fix.md`
- `2026-02-04-slide-layout-patterns.md`

## Entry Template

```markdown
# Learning: [Brief Title]

**Date:** YYYY-MM-DD
**Category:** [bug-fix | optimization | new-capability | best-practice | user-preference]
**Severity:** [minor | moderate | significant]

## What Happened

[Describe the situation or task]

## What Went Wrong / What Was Learned

[Describe the mistake, inefficiency, or new insight]

## Correction / Improvement

[Describe what was changed or should be done differently]

## Impact

[How does this affect future behavior?]

## Files Updated

- [List any files that were updated as a result]
```

## Categories

| Category | Description |
|----------|-------------|
| `bug-fix` | Corrected an error in logic or output |
| `optimization` | Found a more efficient approach |
| `new-capability` | Learned a new skill or technique |
| `best-practice` | Identified a pattern worth repeating |
| `user-preference` | Learned user's preferred style or approach |

## Review Process

Periodically review learnings to:
1. Update `CLAUDE.md` with persistent behavior changes
2. Update skill documentation with new patterns
3. Archive old learnings that have been incorporated

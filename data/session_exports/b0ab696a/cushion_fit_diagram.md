## The Connected Cushion Advantage

**How a connected cushion works on your barrel-back:**

```
    1. Drapes over curved back
         │
         ▼
    ┌────────┐
    │  BACK  │
    │ SECTION│
    │        │
    └────────┘
         │ ← FLEXIBLE HINGE/FOLD POINT
         │    (conforms to seat-to-back curve)
         ▼
    ┌────────┐
    │  SEAT  │
    │ SECTION│
    │        │
    └────────┘
         │
         ▼
    3. Settles into seat depression

ONE CONTINUOUS PIECE = No sliding, no gaps, no readjustment
```

**Separate cushions on your barrel-back:**

```
    ┌────────┐
    │  BACK  │  ← Slides down curved back
    │        │
    └────────┘
         │
         ▼  GAP FORMS HERE ✗
         │
    ┌────────┐
    │  SEAT  │  ← Slides forward on angled seat
    │        │
    └────────┘

CONSTANT READJUSTMENT REQUIRED ✗
```

## Instructions

Create flashcards following these formatting rules:

**Questions:**
- No filler words — direct and testable
- Include count when asking for lists (e.g., "4 components of Enterprise Value?")
- Use `**Org:**` prefix for firm-specific facts

**Answers:**
- Single line, keywords only
- Use numbered format: `(1) Item, (2) Item, (3) Item`
- No full sentences — just the testable fact

**Coverage areas:**
- Technical questions (valuation, accounting, modeling)
- Market sizing / brain teasers
- "Walk me through" process questions
- Firm-specific knowledge

**Structure:**
- One testable fact per card
- Break nested information into separate cards
- Separate question and answer with a newline
- Separate cards with a blank line

## Output Format

Output cards as plain text — one question line, one answer line, blank line between cards:

```
Question text here?
Answer text here

Next question?
Next answer
```
